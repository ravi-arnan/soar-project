 [1] MALWARE - AUTO-ISOLATE  (keyakinan tinggi)
------------------------------------------------------------------------------
  printf '%s' 'X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*' > ~/Downloads/malware-demo.com

  HASIL (~15-30 dtk): Telegram "OTOMATIS DIISOLASI" (tanpa tombol).
  BUKTI:  ls ~/Downloads/malware-demo.com    -> HILANG

  NARASI: "VirusTotal yakin (sekitar 59 dari 70 antivirus). Menunggu manusia
           hanya menambah risiko, jadi SOAR karantina otomatis - MTTR ~ nol."


------------------------------------------------------------------------------
 [2] MALWARE - TOMBOL  (ambigu, human-in-the-loop)
------------------------------------------------------------------------------
  echo "dokumen kerja yang sah" > ~/Downloads/demoreview-laporan-rapat.txt

  HASIL: Telegram dengan tombol [Isolasi File] [Abaikan].
  AKSI:  TAP "Isolasi File" di HP -> pesan jadi "DIISOLASI", file dikarantina.

  NARASI: "Untuk deteksi rendah / ambigu, daripada salah karantina file kerja
           yang sah, sistem serahkan keputusan ke analis lewat 1 klik di
           Telegram - human-in-the-loop. Hindari isolasi buta."


------------------------------------------------------------------------------
 [3] FILE BERSIH - ANTI FALSE-POSITIVE  (bintang!)
------------------------------------------------------------------------------
  echo "foto liburan biasa" > ~/Downloads/foto-liburan.jpg

  HASIL: Telegram TETAP SUNYI (VirusTotal bersih, 0 deteksi).

  NARASI: "Dulu tiap unduhan - foto, ISO, config - dianggap malware = alert
           fatigue. Sekarang sistem hanya bersuara saat VirusTotal benar-benar
           menemukan sesuatu. Ini yang membedakan SOAR matang dari penerus alert."


------------------------------------------------------------------------------
 [4] PHISHING - AUTO-BLOCK
------------------------------------------------------------------------------
  bash scripts/test-phishing.sh "http://testsafebrowsing.appspot.com/s/phishing.html"

  HASIL (~40 dtk, tunggu URLScan): Telegram info + domain di-sinkhole.
  BUKTI:  grep testsafebrowsing /etc/hosts   -> 0.0.0.0 ...

  NARASI: "Google Safe Browsing menandai phishing, domain langsung di-sinkhole
           otomatis ke 0.0.0.0 - korban tidak bisa mengakses situsnya."


------------------------------------------------------------------------------
 [5] PHISHING - TOMBOL BLOKIR
------------------------------------------------------------------------------
  bash scripts/test-phishing.sh "http://demoreview-phish-test.example.org/login"

  HASIL: Telegram dengan tombol [Blokir] [Abaikan].
  AKSI:  TAP "Blokir" di HP -> domain di-sinkhole di /etc/hosts.

  NARASI: "Sama seperti malware - phishing yang ambigu juga bisa diserahkan ke
           analis untuk keputusan akhir."

==============================================================================
 TROUBLESHOOTING CEPAT
==============================================================================
  Telegram lama (>1 mnt)      -> Ollama dingin / VT lambat. Wajar, jelaskan.
  Notifikasi tak muncul       -> Cek workflow Active di n8n; docker logs n8n --tail 20
  Tombol diklik tak ada efek  -> docker logs tg-callback-poller --tail 10
                                 (harus ada "forwarded callback_query")
  Agent tak Active            -> sudo systemctl restart wazuh-agent
  FIM rewel                   -> picu lewat webhook langsung (lihat KARTU-DEMO.md bagian 6)
