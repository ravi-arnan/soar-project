1. Kemajuan Teknis yang Dilaporkan Minggu Ini

A. Deteksi Pre-Encryption Ransomware (MITRE T1490 & T1547.001)
Mengadaptasi aturan deteksi dari Microsoft Azure Sentinel & SigmaHQ ke dalam scripts/process-chain-rules.xml (Rule 110039-110044). Mendeteksi upaya malware melumpuhkan backup Windows (vssadmin delete shadows, bcdedit) dan autostart persistence di Registry/Task Scheduler. Unit test lolos 100%.
B. Studi Komparasi Empiris: n8n vs Shuffle SOAR di Localhost
Melakukan pengujian nyata terhadap Shuffle SOAR (platform pembanding terpopuler). Terbukti Shuffle memerlukan klaster OpenSearch ~4,5 GB RAM dengan Docker-in-Docker overhead, sedangkan arsitektur n8n kita hanya butuh ~400 MB RAM (hemat >90% memori), sangat ideal bagi UKM.
C. Garansi Transmisi Callback Telegram (Anti-Downtime)
Pembaruan tg-callback-poller.py dengan mekanisme offset protection: jika server n8n sempat terputus sesaat, klik tombol analis (Karantina/Abaikan) tidak akan hilang dan otomatis diteruskan ulang begitu server pulih.
D. Harmonisasi Host Network Health Monitor
Kontainer pemantau kesehatan dialihkan ke host network untuk mengeliminasi false alarm status Wazuh API, menjaga riwayat status agen tetap utuh saat inspeksi jaringan berlangsung.

3. Alur Panduan Demo Langsung (Live Demonstration)

  1. Notifikasi & Keputusan Telegram: Tunjukkan bot Telegram menerima alert indikasi file malware dengan rincian hash, skor konsensus VirusTotal, dan tombol aksi [Karantina File] / [Abaikan]. Klik tombol dan perlihatkan update audit trail seketika.
  2. Dashboard Web Fleet Monitor: Tunjukkan antarmuka web monitoring: visualisasi donut severity, status koneksi 100+ agen kasir, dan ringkasan event ancaman realtime.
  3. Verifikasi Beban Rendah Agen: Tunjukkan terminal endpoint dengan perintah top/htop: proses soar-agent hanya memakan RAM ~7 MB dan 0% CPU.

4. Antisipasi Tanya Jawab Kritis

Q: “Kenapa agen dibuat dengan Rust, bukan Go seperti yang saya contohkan?”
→ “Rust menghasilkan binary statis tanpa overhead runtime dan garbage collector, sehingga penggunaan RAM bisa ditekan hingga hanya ~7 MB (dibanding Go yang ~15-25 MB). Sangat aman untuk komputer kasir toko ber-RAM terbatas.”
Q: “Apakah sistem aman dari risiko salah hapus dokumen kerja kasir?”
→ “Sangat aman. Sistem menerapkan Human-in-the-Loop: file ambigu (skor 1-19) tidak dihapus otomatis, melainkan wajib persetujuan analis via Telegram. Ada juga proteksi pembatasan direktori sistem operasi.”
